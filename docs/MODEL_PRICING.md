## 计费规则

- 峰时为 UTC 周一至周五的 `01:00-04:00` 和 `06:00-10:00`，其他时间为谷时。
- 中国法定节假日可能影响峰谷分类；当前配置尚未接入节假日日历。
- 输入 Token 中，缓存命中部分按缓存价格计费，其余部分按缓存未命中价格计费。
- 推理 Token 已包含在输出 Token 中，不重复收费。
- 金额由 Token 数量乘以公开单价估算，不包含优惠、赠金、税费或供应商最终账单差异。
- 最终实际扣费以 DeepSeek 平台账单为准。
